BEFORE memory: Fresh native agent and empty native memory for each episode; the agent sees each delivered observation's evidence_id as its journal label (obs-N), and its report's cited labels are decoded back to the full evidence IDs before validation.

AFTER memory: Fresh native agent and empty native memory for each episode. The agent is shown each observation's evidence_id as a short label obs-N, numbered 1, 2, 3, ... in the order the observations were first shown to it; an observation it was never shown (for example the first attempt of a write the broker retried inside one tool call, or a policy step's read that did not block) gets no label. When it submits its report, each cited label it had been shown is decoded back to the full evidence ID before validation, and any other cited token is kept exactly as written. So a report in these records cites the same full evidence IDs as the recorded observations; a token kept as written is one the agent was never shown as a label, and it fails the evidence check. In an evidence summary a report citation oN means the Nth observation row of that episode; that numbering counts every recorded observation, including ones the agent never saw, so it can differ from the agent's obs-N.
