# effectsafe

Name reserved on PyPI for `effectsafe`, a runtime action layer for LLM agents that change the world: every mutating tool call gets an identity pinned to the agent's intent, the provider's idempotency key, an exact-bytes journal, a receipt, and an honest PENDING or UNKNOWN outcome instead of a silent second effect. Per-provider connector profiles are certified in the FaultLab lab.

This placeholder installs an empty module. The first real release follows the FaultLab v2 rebuild at https://github.com/ShreeBohara/faultlab.
