# faultlab

Name reserved on PyPI for FaultLab, an effect-level reliability lab for agents that act: it injects the faults real services produce (a write commits but the reply is lost, an action is accepted now and rejected later, a stale read, a request delivered twice), records what actually happened in the service, and compares that with what the agent claimed.

This placeholder installs an empty module. The first real release follows the v2 rebuild at https://github.com/ShreeBohara/faultlab.
