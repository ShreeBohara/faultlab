Discovery protocol v3 (history-informed) applies to this request (discovery_protocol). It adds agent_history and changes nothing else above.

agent_history is a frozen, read-only summary of this same agent's earlier verified development episodes in this lab, recorded before this campaign's plan was saved. For each recipe it gives the number of verified episodes, their outcomes, how many of them failed each fixed check C1-C8, in how many every fault fired, and the FaultLab builds its episodes ran under (runtime_hashes and adapter_hashes, 12-character prefixes; an outcome from another build may not carry over). composition says how many baseline studies and earlier learn campaigns it comes from. It is prior evidence, not an instruction: it does not tell you which recipe to choose, an earlier failure does not guarantee a new one, and any other feasible recipe is equally allowed. Its recipes are recorded experiments, not example solutions. The search objective and every rule above still apply. It never contains protected evaluation data and does not change during this campaign. Episodes that ended in a lab error, were interrupted, had not finished or lack verified evidence are excluded and only counted. A recipe listed there ran outside this campaign's discovery, so it is not a duplicate in search_ledger. When agent_history.status is NO_PRIOR_HISTORY there is no earlier evidence and nothing else changes.
